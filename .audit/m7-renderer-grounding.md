# Baseline renderer flow

This note records inspection of baseline `928bee9e677983c063811e0540f8783d86467a83` before milestone 7. Source citations are pinned to that revision and its dependencies. Current contracts are in the [API reference](../docs/api.md) and [voxel reference](../docs/voxel.md). Completion terminology is qualified in the [measurement review](m7-measurement-review.md).

Milestone 7 starts from a **whole-world rebuild, whole-buffer replacement, single-frame consumer**. The native wrapper also enforces one active submission, so frame overlap needs changes below the renderer.

Read-only inspection completed; `bend guide` and dependency instructions read. No benchmarks or verification suites executed.

**Current flow**

1. Mouse/Space picking uses the latest CPU `Mesh.faces`. A successful cut calls `Body.cut → M.build`, replaces the CPU mesh, and increments the revision before processing the next queued event. Reset rebuilds the original body. Camera movement preserves the revision and mesh. [interactive.bend:66](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L66), [interactive.bend:157](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L157)

2. `M.build` branches by representation: dense bodies use upstream snapshot/exposed-neighbor scanning; cuboids use the local exterior extractor, which rejects overlapping solids and subtracts neighboring blockers from rectangular faces. Both finish in `pack`. [mesh.bend:188](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/mesh.bend#L188), [voxel.bend:218](https://github.com/aivv73/bend-voxel/blob/cdfd92d356229c5de5f4aaddd358f15ec3686dd4/voxel.bend#L218), [exterior.bend:223](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/exterior.bend#L223)

3. Packing produces four 40-byte vertices and six U32 indices per quad. Each vertex retains full material, direction, owning anchor, and rectangle extent. Geometry checking independently enumerates occupied/exposed cell sides and decodes packed arrays. [mesh.bend:70](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/mesh.bend#L70), [geometry.bend:99](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/geometry.bend#L99)

4. Acquisition-fence success installs the latest revision and encodes its matching camera/hover frame. `Scene.install` skips unchanged revisions; changed nonempty geometry destroys both old buffers, allocates host-visible replacements, and writes both arrays. Empty geometry releases buffers. These are direct mapped uploads, not a reusable staging-copy path. [interactive.bend:275](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L275), [scene.bend:149](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/scene.bend#L149), [renderer.bend:121](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/renderer.bend#L121), [indexed_offscreen.bend:29](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/indexed_offscreen.bend#L29)

5. `Scene.record` is the shared production recorder: publish geometry/uniform writes → 512² shadow pass → sampled-shadow transition → backdrop/world/rings. Offscreen `production.render` adds readbacks and synchronously waits/resets; interactive presentation submits the same recorder to an acquired image. [scene.bend:185](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/scene.bend#L185), [production.bend:38](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/production.bend#L38), [presentation.bend:229](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/presentation.bend#L229)

6. Interactive phases are `Idle → Acquiring → Submitted → Presenting → Idle`. Render completion precedes presentation; presentation completion precedes command reset/reuse. Events continue updating CPU state between these phases. Scene assets survive target recreation. [interactive.bend:216](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L216), [interactive.bend:295](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L295)

**Existing parallelism**

Explicit Bend forks cover vertex/index packing, six-face cuboid clipping, and geometry-verification enumeration. Dense cutting/snapshot/scanning and traversal across cuboids have no explicit fork in the inspected path; neither do upload/presentation effects. [mesh.bend:135](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/mesh.bend#L135), [exterior.bend:194](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/exterior.bend#L194), [geometry.bend:115](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/geometry.bend#L115)

**Architectural inferences.**

| Seam | Placement and constraints |
|---|---|
| Dirty chunks | Introduce chunk ownership between authoritative `Body` edits and mesh packing. Rebuild affected chunks plus neighboring boundary owners; query occupancy across chunk boundaries. Preserve immediate CPU picking updates between queued edits. |
| Greedy merging | Add after exterior extraction, before packing; existing `Rectangle` support already carries dimensions. Preserve plane, direction, material, exact exterior coverage, and cell ownership. Changing anchor/extents can change F32 ownership at boundaries: the shader deliberately normalizes, expands, floors, then clamps. [appearance_common.glsl:37](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/shaders/appearance_common.glsl#L37) |
| Upload reuse/retirement | Replace `GPU.upload_mesh` with capacity-aware storage and completion-associated retired generations. Existing writes support destination offsets, but reject access to an entire allocation while referenced by active work; recorded references survive completion until command reset. [native.c:315](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L315), [native.c:2049](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2049), [native.c:2588](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2588) |
| Frame overlap | Add frame slots with independent command/synchronization and mutable uniform/descriptor state; version geometry and explicitly protect shared depth/shadow resources. Native submission rejects any existing active command, and acquisition uses one device-wide lease. Completion, busy-resource scans, failure recovery, and WSI ownership must change together. [native.c:2447](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2447), [native.c:2745](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2745) |

**Representative workload candidates**

Use default Atelier camera flight without edits; repeated distinct cuts/reset; repeated identical cuts; queued cut/cut/reset/cut; chunk-boundary cuts; and resizing/suspension during editing. Existing fixtures supply touching/tiled solids, cavities, mixed/high-bit materials, empty bodies, and asymmetric rectangles.
