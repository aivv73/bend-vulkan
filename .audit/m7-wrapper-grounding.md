# Baseline wrapper ownership

This note records inspection of baseline `928bee9e677983c063811e0540f8783d86467a83` before milestone 7. Source citations are pinned to that revision and its dependencies. Current contracts are in the [API reference](../docs/api.md) and [voxel reference](../docs/voxel.md). Completion terminology is qualified in the [measurement review](m7-measurement-review.md).

The main constraint is **one active submission and one acquisition lease per device**. Milestone 7 requires changing that lifecycle model; extra command buffers and fences alone will not enable overlap.

**Facts from inspection**

- **Ownership lives in C.** Bend handles are copyable checked U32 keys. `BvRow` stores native handles, parent ownership and dependency edges; keys never repeat. `Entry.with` runs cleanup after its callback, and cleanup preserves the entry when completion fails. See [Vulkan.bend:5](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/Vulkan.bend#L5), [src/native.c:81](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L81), [src/native.c:206](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L206), [Vulkan.bend:749](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/Vulkan.bend#L749), [src/native.c:504](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L504).

- **Recorded references outlive completion.** Recording allocates deduplicated `BV_DEP_RECORDED` edges before dispatch. Dependencies transitively retain buffers → memory, framebuffer → views/images, and descriptor sets → uniform buffers/sampled resources. Completion clears submission associations, but recorded references remain until successful command reset or pool destruction. Failed reset retains them. Descriptor updates reject any referenced set, including completed recordings. See [src/native.c:332](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L332), [src/native.c:249](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L249), [src/native.c:1656](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L1656), [src/native.c:2588](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2588).

- **Packed destination-subrange writes already exist.** `write_memory_words` takes destination offset and byte length, reads from array byte zero, emits low-order bytes first, supports partial final words, and returns the unchanged array on every result. It accepts packed and Term arrays, limits each write to 16 MiB, temporarily maps the entire allocation and flushes the entire noncoherent allocation. There is no source-array offset. Host exclusion is allocation-wide. See [src/native.c:2005](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2005), [src/native.c:2049](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2049), [src/core.bend:60](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/core.bend#L60).

- **GPU subrange copies also exist.** `BufferCopy` carries U64 source offset, destination offset and size. Native validation checks ranges, usages, destination overlap and physical-memory alias overlap, with up to 4096 regions. Barriers remain explicit caller operations. See [Vulkan.bend:166](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/Vulkan.bend#L166), [src/native.c:2183](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2183).

- **Submission completion is explicitly observed.** Commands follow Initial → Recording → Executable → Pending → Completed. Submission requires no other active command on the device and an unsignaled free fence. OOM leaves the command executable; other uncertain submit errors retain resources in Uncertain and require device-idle recovery. Fence timeout/NOT_READY preserves Pending. `submit_and_wait` reuses one private fence. See [src/native.c:25](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L25), [src/native.c:2447](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2447), [src/native.c:2517](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2517), [src/native.c:2602](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2602).

- **Several helpers assume that single active command.** `bv_memory_busy` examines only the first active command; `bv_idle` completes only one; `bv_complete` changes the device's global lease phase without identifying a particular lease. These assumptions must change together. Acquisition additionally rejects an existing lease, active submission or previous recording referencing the swapchain. Presentation requires observed rendering completion and has its own maintenance1 completion fence. See [src/native.c:281](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L281), [src/native.c:315](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L315), [src/native.c:2745](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2745), [src/native.c:2801](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2801).

- **The consumer currently uploads directly into host-visible geometry buffers.** Each changed mesh releases the old buffers, allocates replacements and writes whole vertex/index payloads. Production assets share one camera uniform and shadow attachment; the presentation target shares one depth attachment. The application serializes acquire → render → present → reset. See [examples/voxel/renderer.bend:121](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/renderer.bend#L121), [examples/indexed_offscreen.bend:29](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/indexed_offscreen.bend#L29), [examples/voxel/scene.bend:13](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/scene.bend#L13), [examples/voxel/presentation.bend:16](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/presentation.bend#L16), [examples/voxel/interactive.bend:275](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L275).

- **Diagnostics are currently counts and state logs.** Public `debug_live_objects` counts registry rows, not bytes or allocations. Metadata allocation counters are injected into emitted C by verification tools; window instrumentation also counts acquisitions. `STATE` logs report revisions, uploads, quads and completed frames. No timestamp-query bindings exist; native device state already retains full queue properties and physical-device limits. See [src/native.c:2627](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L2627), [tools/check_native.py:43](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tools/check_native.py#L43), [tools/check_window.py:351](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tools/check_window.py#L351), [examples/voxel/interactive.bend:336](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/examples/voxel/interactive.bend#L336), [src/native.c:948](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/native.c#L948).

**Recommended extension points**

| Capability | Placement and constraint |
|---|---|
| Reusable staging | Add a reusable upload owner above raw buffer/memory effects. Start with separate allocations per frame slot; current allocation-wide exclusion prevents writing an unused region of a still-busy allocation. |
| Source subranges/chunk uploads | Extend the packed-write boundary with a checked source byte offset while preserving returned-array ownership. Reuse existing `copy_buffer` regions. Put pure overflow/range rules beside [src/core.bend:64](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/src/core.bend#L64) and packing laws in [LAWS.bend:52](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/LAWS.bend#L52). |
| Deferred release | Retire resources against a submission generation, then reclaim after completion **and** successful retirement of all recorded references. A reusable fence key alone cannot identify an old submission after reset. |
| Multiple frames | Replace global lease assumptions with per-acquisition associations; inspect every active command for host exclusion and idle completion. Give each frame its own camera storage/descriptors and safe shadow/depth ownership, or provide explicit ordering. |
| Timestamps | Add checked query-pool ownership, recording references, reset/write/results effects and cleanup. Expose timestamp period/valid bits, preserve U64 ticks, and report availability/wrap limits separately from CPU/upload/presentation durations. |
| Optional suballocation | Build above existing offset binding checks. Disjoint buffer/optimal-image allocations already have real-device coverage in [tests/image_probes.c:44](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tests/image_probes.c#L44); no allocation manager exists. |

**Generator policy:** edit the manifest and handwritten native implementation, then regenerate. The only supported policies are `return_owner` and `native_module`; packed writes use `return_owner: 4`. The generator emits declarations, registrations, native-only JS errors and constants. Native marshalling remains handwritten. `src/window.c` is generated by concatenating `native.c` and `x11.c`; do not edit it directly. See [tools/bindings.json:21](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tools/bindings.json#L21), [tools/generate.py:57](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tools/generate.py#L57), [tools/generate.py:83](https://github.com/aivv73/bend-vulkan/blob/928bee9e677983c063811e0540f8783d86467a83/tools/generate.py#L83).
